=============================================================
PLAN DE PROYECTO - CLUB DE LECTURA PAGO
=============================================================

Resumen del proyecto:
- Club de lectura con suscripcion mensual + microtransacciones (sesiones extra)
- Sin almacenar datos personales (solo email para identificar cuenta)
- 50-200 miembros iniciales
- Ubicacion: LATAM
- Presupuesto hosting: Lo mas barato posible (idealmente gratis)
- Autenticacion: Login con Google (OAuth)

=============================================================
1. STACK TECNOLOGICO RECOMENDADO
=============================================================

FRONTEND:
  - HTML5 + CSS3 + JavaScript vanilla
  - Framework CSS: Tailwind CSS (rapido de aprender, moderno)
  - No se necesita framework de JS pesado (React, Vue) para este tamano

BACKEND:
  - Node.js + Express.js
  - Razon: Ya estas en el mundo JS, es el camino mas natural
  - Sirve como API REST que conecta frontend con servicios externos

BASE DE DATOS + AUTH:
  - Supabase (https://supabase.com)
  - Plan GRATIS incluye:
    * PostgreSQL (base de datos relacional)
    * Autenticacion con Google OAuth integrada
    * 500 MB de almacenamiento
    * 50,000 usuarios activos mensuales
    * API REST automatica
  - NO necesitas configurar OAuth manualmente, Supabase lo hace

PASARELA DE PAGO:
  - Mercado Pago (https://mercadopago.com)
  - Razon: Ideal para LATAM
    * Acepta tarjetas de credito/debito locales
    * Acepta PSE, OXXO, Rapipago, etc.
    * Soporta suscripciones recurrentes
    * Soporta pagos unicos (microtransacciones)
    * Comision competitiva en LATAM
  - Alternativa: Stripe (disponible en Mexico, Brasil, Colombia)
    * Mejor documentacion tecnica
    * API mas robusta
    * Pero menos metodos de pago locales en LATAM

HOSTING (FRONTEND):
  - Netlify (https://netlify.com) - GRATIS
    * Hosting estatico para HTML/CSS/JS
    * Deploy automatico desde GitHub
    * Certificado SSL incluido
    * Dominio personalizado gratis

HOSTING (BACKEND - API):
  - Railway (https://railway.app) - Gratis hasta cierto uso
    * $5 de credito mensual gratis
    * Suficiente para 50-200 usuarios
  - Alternativa: Render (https://render.com)
    * Plan gratuito disponible
    * Se duerme tras inactividad (normal para poco uso)

3. MODELO DE BASE DE DATOS (Supabase)
=============================================================

Tabla: usuarios
  - id            UUID (generado por Supabase Auth)
  - email         TEXT (del login con Google)
  - rol           TEXT ('free', 'suscriptor', 'admin')
  - fecha_registro TIMESTAMP
  - mp_customer_id TEXT (ID del cliente en Mercado Pago)

Tabla: suscripciones
  - id            SERIAL PRIMARY KEY
  - usuario_id    UUID (FK -> usuarios.id)
  - plan          TEXT ('mensual')
  - estado        TEXT ('activa', 'cancelada', 'vencida')
  - mp_subscription_id TEXT (ID de suscripcion en Mercado Pago)
  - fecha_inicio  TIMESTAMP
  - fecha_fin     TIMESTAMP
  - precio        DECIMAL

Tabla: sesiones
  - id            SERIAL PRIMARY KEY
  - titulo        TEXT
  - descripcion   TEXT
  - fecha         TIMESTAMP
  - hora          TIME
  - link_reunion  TEXT (enlace de Zoom/Meet)
  - tipo          TEXT ('regular', 'especial')
  - precio        DECIMAL (0 si es regular, precio si es especial)
  - imagen_url    TEXT

Tabla: libros
  - id            SERIAL PRIMARY KEY
  - titulo        TEXT
  - autor         TEXT
  - genero        TEXT
  - descripcion   TEXT
  - imagen_url    TEXT
  - mes_asignado  TEXT (ej: 'Julio 2026')
  - sesion_id     INT (FK -> sesiones.id)

Tabla: compras_sesiones_extra
  - id            SERIAL PRIMARY KEY
  - usuario_id    UUID (FK -> usuarios.id)
  - sesion_id     INT (FK -> sesiones.id)
  - monto         DECIMAL
  - fecha_compra  TIMESTAMP
  - mp_payment_id TEXT

Tabla: registros_sesiones
  - id            SERIAL PRIMARY KEY
  - usuario_id    UUID (FK -> usuarios.id)
  - sesion_id     INT (FK -> sesiones.id)
  - asistio       BOOLEAN

4. MODELO DE PAGO - SUSCRIPCION + MICROTRANSACCIONES
=============================================================

SUSCRIPCION MENSUAL (via Mercado Pago):
  - Precio: $250 MXN/mes (ajustable)
  - Incluye:
    * Acceso a todas las sesiones regulares mensuales
    * Acceso al libro del mes
    * Grupo de participantes (redes sociales)
    * Atencion privada
    * Grabaciones de sesiones anteriores
  - Primer mes gratis (trial)
  - Cancelacion en cualquier momento

MICROTRANSACCIONES - SESIONES EXTRA:
  - Sesiones especiales con autores invitados
  - Talleres de escritura
  - Sesiones de generos especificos
  - Book talks extra
  - Precio por sesion: $50-100 MXN (ajustable)
  - Pago unico, no requiere suscripcion

FLUJO DE PAGO:
  1. Usuario nuevo -> Click en "Unete ya!" -> Login con Google
  2. Supabase crea la cuenta (solo email)
  3. Redirige a checkout de Mercado Pago (suscripcion)
  4. Mercado Pago procesa el pago
  5. Webhook notifica al backend -> actualiza estado en BD
  6. Usuario accede al dashboard con contenido

=============================================================
5. FLUJO DE AUTENTICACION (Sin guardar datos personales)
=============================================================

1. Usuario hace click en "Iniciar sesion con Google"
2. Supabase maneja el popup de Google OAuth
3. Google retorna: email + ID unico de Google
4. Supabase crea registro en tabla "usuarios" con:
   - id (UUID unico)
   - email (unico dato personal necesario)
   - rol: 'free'
5. Se guarda session en localStorage
6. El backend verifica el token JWT en cada peticion protegida

NO se guarda:
  - Nombre completo
  - Numero de telefono
  - Domicilio
  - Datos de tarjeta
  - Nada mas alla del email

9. CONSIDERACIONES IMPORTANTES
=============================================================

SEGURIDAD:
  - NUNCA subir .env a GitHub
  - Usar .gitignore correctamente
  - Verificar tokens JWT en cada peticion protegida
  - Sanitizar inputs del usuario
  - Usar HTTPS en produccion (Netlify lo da gratis)

SIN DATOS PERSONALES:
  - El unico dato guardado es el email (necesario para identificar)
  - No hay formulario de registro tradicional
  - No se guarda nombre, telefono, direccion
  - Google se encarga de la autenticacion

ESCALABILIDAD:
  - Supabase plan gratis soporta 50,000 usuarios
  - Mercado Pago no tiene limite de transacciones
  - Si creces mas de 200 usuarios, considerar upgrade
    de hosting (Railway/Render plan pago ~$5-20 USD/mes)

BACKUPS:
  - Supabase hace backups automaticos en plan gratis
  - Puedes exportar datos manualmente desde el dashboard
  - Considerar backup semanal del codigo en GitHub
